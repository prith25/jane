# Margaret's Birthday Project

A static birthday experience for Margaret, designed for GitHub Pages.

## Current baseline
This project starts from the previously supplied birthday project files:
- `index.html`
- `styles.css`
- `script.js`

## Planned experience
1. Violet-themed invitation screen with YES / NO interaction.
2. Birthday countdown until 27 November 2026, 12:00 AM India Standard Time.
3. Animated birthday envelope and personalized letter.
4. Chocolate birthday cake with age 25, candle-blowing, confetti, and cake-cutting interactions.

## Hosting
This is intended for GitHub Pages. No Firebase or backend is required.

The current files are the unmodified starting point. The planned screens and behavior will be implemented in the next iteration.
